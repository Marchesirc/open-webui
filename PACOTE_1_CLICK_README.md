# Pacote 1-clique

## Arquivos criados
Na raiz de `D:\Projetos`:

- `Iniciar_OpenWebUI_Proteus.bat`
- `Reinstalar_OpenWebUI_Proteus.bat`
- `Configurar_Proteus_Automacao.bat`

## Uso
### Iniciar tudo
Clique duas vezes em:
- `Iniciar_OpenWebUI_Proteus.bat`

### Reinstalar tudo após formatação
Clique duas vezes em:
- `Reinstalar_OpenWebUI_Proteus.bat`

### Reconfigurar a automação do Proteus
Clique duas vezes em:
- `Configurar_Proteus_Automacao.bat`
